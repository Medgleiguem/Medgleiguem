# Profile maintenance

The profile uses native Markdown for substantive content and local SVGs for decoration. There are no remote stats widgets, counters, font downloads or image-generation services.

Run `python3 tools/generate_assets.py` to rebuild the four banner/footer assets. It uses only the Python standard library. Commit the generated SVGs with their source. The README selects a separate mobile composition below 600px. CSS animation respects `prefers-reduced-motion`. The animated contribution graph also has a static fallback.

The contribution animation is generated by `.github/workflows/snake.yml`. It reflects GitHub's available contribution data, not an inventory of private projects. `assets/contributions-static.svg` is a fixed reduced-motion snapshot; regenerate it from a current output if desired by disabling CSS animations, retaining initial cell fills and omitting the snake and progress bar.

Content is based on the owner's supplied CV and project documentation. Institutional impact figures describe the programs supported, not independently audited personal impact. Research plans are labeled as ongoing or in design. Do not add private repository links, internal documents, credentials or unsupported claims. Do not present third-party security tools or repository backups as original creations.

Before publishing, check local image paths and SVG XML, render on desktop and mobile, test reduced motion, and check public links in a signed-out browser. Use a normal fast-forward push and preserve remote workflow commits.
