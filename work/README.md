# Domains, toolkit & selected work

The methods, tools and projects behind the profile. The toolkit spans my work and practice; each engineering brief describes its own implementation and current boundaries. Institutional source code is private.

<a id="domain-ai"></a>

## AI systems & retrieval

RAG, LLM integration, lexical/hybrid retrieval, document processing, source citations, corpus provenance and human review. Broader ML interests include fraud detection and predictive modeling.

**Toolkit:** Python, FastAPI, PostgreSQL/pgvector, Docling, SQLAlchemy; Claude, Groq and Gemini APIs.

- [Health Ministry AI](./health-ministry.md) — domain-scoped evidence, dossiers and human decisions.
- [Central Bank / RKF](./central-bank.md) — document identity, hybrid retrieval and review boundaries.
- [ARE Intelligence](./are-intelligence.md) — regulatory evidence and lexical retrieval; generated answers are currently disabled.
- [National Knowledge Base](./national-knowledge.md) — imports, provenance and staff review; customer publication/retrieval remains later work.

Related experiments include fraud detection in a banking datathon and soil-condition prediction in an AI hackathon.
